# 求职助手 · 投递进度追踪

**一个纯前端、零依赖的求职管理系统：投递追踪 + 经历库 + 简历工坊三合一，全部数据存在浏览器本地，双击 HTML 即用。**

个人产品项目 · 独立开发 · 2026-09

---

## 解决的问题

秋招/实习投递的典型痛点是：信息过载、岗位匹配判断耗时、逐 JD 改简历繁琐、投递记录散落在表格和聊天记录里。这个工具把「信息 → JD 匹配 → 简历修改 → 投递 → 记录」整条链路收进一个单文件应用。

## 三大模块

### 1. 投递追踪

一张主表作数据源，配多个联动视图（延续 WPS「一张主表 + 多 sheet 联动」思路）：

- **总表**：公司、行业、岗位类型、进度、下一步、截止日、投递日、优先级、JD 链接、简历附件、备注、历史进度
- **看板视图**：按进度 / 招聘类型 / 行业 / 机构类型 / 优先级分组
- **甘特视图**：按时间轴看投递节奏与关键节点

### 2. 经历库

- 通用经历底稿（按「标题 | 机构 | 时间 | 要点 | 成果 | 标签」结构化）
- 内置一份**脱敏示例经历包**，可一键载入体验（界面按钮「载入示例经历包」）
- 支持按标签筛选、去重、导入导出

### 3. 简历工坊

- 按 JD 匹配挑选经历、微调描述、生成简历
- 内置大陆 / 香港 × 产品 / 运营 / 商业分析 / 金融 四类模板
- 支持打印 / 导出

## 技术特点

- **单文件 HTML**，无构建、无后端、无外部依赖，双击 `index.html` 即可运行
- 数据存于浏览器 `localStorage`，隐私不出本机
- 原生 JS，约 2,100 行，含完整的增删改查、看板渲染、简历生成逻辑
- 附功能测试脚本思路（见项目复盘）

## 运行方式

```bash
# 直接双击 index.html，或
python -m http.server 8000   # 然后访问 http://localhost:8000
```

首次打开会自动载入示例经历包（脱敏数据，可在界面内编辑或删除）。

## 关于这个项目的定位

这是一个**真实自用、解决我自己求职痛点的效率工具**，不是 AI 项目——它体现的是需求洞察、信息架构和把复杂流程收进单文件产品的动手能力，作为产品岗作品集的"执行力佐证"。真正的 AI 能力项目见同主人的 `smartbuy-ai-shopping-advisor`（购物决策 Agent）与 `fund-checkup`（LLM 解读）。

仓库内为脱敏版：内置的姓名、邮箱、手机、政治面貌、GPA、经历包、简历全文均为示例数据；真实个人档案与投递记录不在仓库中。应用数据存于浏览器 localStorage，不会随仓库分享泄露。
